# OneBots 工作台

在交互式终端运行 `onebots` 或 `onebots ui`，进入同一个工作台。首次安装、账号配置、框架连接和服务运行都在这里完成；页面之间保留同一份配置草稿。`onebots tui` 是兼容入口，不再提供另一套界面。

## 首次进入

已有 OneBots 时，在运行目录执行：

```bash
onebots ui -c config.yaml
```

也可以先下载并运行安装脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/lc-cn/onebots/master/install.sh -o install-onebots.sh
sh install-onebots.sh
```

脚本准备 Node.js 和 OneBots 主程序后打开工作台。适配器、协议依赖只在你确认选择后安装。通过管道执行或设置 `ONEBOTS_NONINTERACTIVE=1` 时走自动部署流程，不打开交互界面。

已有 Node.js 24 或更新版本时，可以创建独立运行目录：

```bash
mkdir my-onebots
cd my-onebots
npm init -y
npm install onebots
npx onebots
```

## 工作区与导航

顶部显示配置文件、服务状态、草稿状态和已选扩展数量。概览给出当前部署的下一步。

| 页面 | 用途 |
| --- | --- |
| 概览 | 查看部署进度，继续配置或上线 |
| 扩展 | 选择平台、安装凭据、输出协议和框架方案，确认后安装与验证 |
| 账号 | 添加、编辑、删除平台账号及平台凭据 |
| 协议 | 为每个账号明确配置并启用协议出口 |
| 框架 | 生成 OneBots 端与框架端连接模板，查看检查步骤 |
| 运行 | 保存并启动或应用配置，查看状态、日志、诊断，停止服务或打开 Web 管理端 |
| 设置 | 编辑网关配置、保存草稿、重新载入、恢复备份 |

页面根部按 **1–7** 跳页，或 **Tab** 切换下一页。列表用方向键移动、空格勾选、Enter 确认；按 **/** 搜索，Esc 退出搜索或返回。长说明和日志用 **PgUp/PgDn** 滚动。表单编辑期间不会响应页面跳转快捷键。

## 从选择到运行

1. 在**扩展**页选择平台。
2. 选择 ICQQ 时，填写有 `@icqqjs` 包读取权限和 `read:packages` 权限的 GitHub Packages Token。输入隐藏，留空使用已有 npm 认证；安装凭据不会写入账号配置或安装摘要。
3. 选择输出协议，再选择下游框架方案。框架列表注明对应协议及验证范围；所需协议未勾选时会返回修改，不擅自加装或启用。
4. 确认运行目录、依赖精确版本、框架和凭据状态。可以返回任一步修改；确认前不会安装扩展。
5. 安装时显示当前阶段与依赖，随后核对包入口、版本和注册结果。验证通过后转到**账号**页。
6. 添加平台账号，再到**协议**页配置该账号的连接方式和鉴权。安装协议包不等于启用出口。
7. 到**运行**页选择“保存并启动 / 应用配置”。工作台校验配置、保存草稿，按需安装守护服务，再启动或重启，并等待在线验证结果。
8. 到**框架**页生成连接说明。框架程序需在下游单独部署；按模板设置地址、连接方向和鉴权，占位凭据需替换。

安装使用运行目录对应的 npm/pnpm，不在 pnpm workspace 中用 npm 解析 `catalog:`。全局或 npx 入口安装好本地 OneBots 后，会切换到本地宿主继续配置，并保留当前草稿。

## 编辑、保存与应用

表单是字段列表，可以任选字段修改，不必每次从头填写。支持枚举、布尔值、数字、条件字段、对象键值和列表项。敏感字段只显示“已设置”，编辑时留空保留已有值。

“完成编辑”把内容保留到工作区草稿，**不会立即写文件或重启服务**。退出已修改的表单时可以继续编辑、保留或放弃；离开整个工作台时，Esc 或退出菜单会确认是否放弃未保存草稿。Ctrl+C 强制结束进程，不保存草稿。

“检查并保存草稿”校验并写入配置，已有文件备份为 `.bak`；配置以私有权限写入。保存后顶部提示“待应用”，需要在运行页应用到服务。启动与重启复用 CLI 的预检和在线验证；验证失败不会显示上线成功。

配置中的 `plugins` 保存平台、协议和框架选择，后续无需重复输入 `-r/-p/-t`。工作台使用当前运行目录解析依赖；管理已有部署时请进入其原运行目录。若服务使用另一份配置，工作台会阻止对它执行停止或上线操作。

## 失败与恢复

| 情况 | 处理方式 |
| --- | --- |
| ICQQ 下载被拒绝 | 在失败页选择修改凭据，检查 Token 权限及包访问资格后重试 |
| 网络或安装失败 | 修复网络或 registry 后重试当前阶段，已选信息保留 |
| 插件验证失败 | 重试验证不会重新安装；仍失败则到运行页诊断或回扩展页修复 |
| 配置校验失败 | 草稿保留，按错误字段回到账号、协议或设置页修改 |
| 文件被外部修改 | 保留内存草稿并阻止覆盖；核对外部变更后，在设置页选择放弃草稿并重新载入，再重新编辑 |
| YAML 损坏 | 工作台仍可进入设置页，从 `.bak` 恢复到草稿，检查后再保存；或手动修复文件后重新载入 |
| 服务启动或重启失败 | 查看运行页的状态、日志和诊断；修复后再次应用配置 |
| 框架无法连接 | 核对两端地址、协议版本、连接方向和鉴权，执行框架页的检查步骤 |

## 命令与自动化

```bash
onebots ui --setup       # 进入扩展页
onebots ui --configure   # 进入账号页
onebots ui --system      # 管理系统级服务
onebots ui --web         # 直接打开 Web 管理端
onebots run             # 显式前台运行网关
```

交互式 `onebots setup` 也进入同一个工作台。非交互终端、CI 和服务内部入口保持命令行模式，继续使用 `setup`、`install`、`start`、`doctor` 等命令。
