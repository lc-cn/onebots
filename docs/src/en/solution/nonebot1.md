# NoneBot 1

NoneBot 1 is registered in the unified Application catalog with the `planned` stage. It cannot be activated with `-t nonebot1` yet; OneBots rejects startup instead of reporting research notes as working support.

| Item | Current value |
| --- | --- |
| Application ID | `nonebot1` |
| Candidate protocols | `onebot.v11` |
| Stage | `planned` |

## Missing implementation

This is a legacy migration target; NoneBot2 remains the recommendation for new deployments.

Promotion to `available` requires a same-name Application package or built-in implementation, protocol capability descriptors, and a pinned-version interoperability gate.
