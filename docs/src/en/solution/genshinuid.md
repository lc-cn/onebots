# GenshinUID

GenshinUID is registered in the unified Application catalog with the `planned` stage. It cannot be activated with `-t genshinuid` yet; OneBots rejects startup instead of reporting research notes as working support.

| Item | Current value |
| --- | --- |
| Application ID | `genshinuid` |
| Candidate protocols | `onebot.v11 / onebot.v12` |
| Stage | `planned` |

## Missing implementation

The gsuid-core connection layer and host-specific gate must be selected separately.

Promotion to `available` requires a same-name Application package or built-in implementation, protocol capability descriptors, and a pinned-version interoperability gate.
