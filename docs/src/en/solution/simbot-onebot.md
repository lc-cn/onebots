# Simple Robot OneBot

Simple Robot OneBot is registered in the unified Application catalog with the `planned` stage. It cannot be activated with `-t simbot-onebot` yet; OneBots rejects startup instead of reporting research notes as working support.

| Item | Current value |
| --- | --- |
| Application ID | `simbot-onebot` |
| Candidate protocols | `onebot.v11` |
| Stage | `planned` |

## Missing implementation

This is a component SDK, so the gate must embed it in a minimal Simbot application.

Promotion to `available` requires a same-name Application package or built-in implementation, protocol capability descriptors, and a pinned-version interoperability gate.
