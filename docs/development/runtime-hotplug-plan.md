# 账号与协议热插拔实施计划

## 目标与约束

管理服务仍是配置的唯一写入者；网关不回写配置。修改账号或协议时按实例应用，
不重启无关账号，不切换网关进程，不中断其他协议入口。扩展运行版本、监听入口等
进程级变更仍须明确授权重启，不能自动降级为全量重启。Changeset 只允许 patch。

实例热插拔以对应扩展已安装、激活并启用为前提；首次启用扩展修改 `plugins`，必须在影响计划中明确作为冷变更展示。

不得用真实平台账号、凭据或生产服务测试。保留用户工作区与配置，测试使用隔离目录。

## 行为矩阵

| 变更 | 运行时动作 | 不应受影响的资源 |
| --- | --- | --- |
| 新增账号 | 创建并启动该账号 | 已有账号与网关进程 |
| 删除账号 | 停止账号及其协议，释放所属资源 | 其他账号、平台共享入口 |
| 账号连接配置 | 准备后只重连该账号 | 其他账号 |
| 协议新增/删除/替换 | 仅协调该协议实例 | 账号平台连接、其他协议 |
| 协议默认值 | 按有效配置找出受影响协议 | 未发生有效变化的协议 |
| 已支持动态字段 | 更新运行配置 | 全部连接 |
| 进程级配置/扩展版本 | 预告影响，显式授权重启 | 未授权前保持现状 |
| 服务端确认网关停止 | 只保存配置，下次启动生效 | 不擅自启动网关；未知状态不能当作停止 |
| 没有有效变化 | 无资源操作 | 所有实例 |

## 架构与职责

```text
Web / CLI / TUI
  → 草稿与验证回执（服务端影响计划）
  → 配置应用事务（既有生命周期串行锁、持久意图、版本 CAS）
  → 私有不可变配置快照
  → 受管子进程 IPC（操作去重、结果查询、实例身份 CAS）
  → 运行态差异协调器
      ├─ 平台作用域：共享 Webhook Host
      ├─ 账号作用域：平台连接、账号注册
      └─ 协议作用域：HTTP/WS/SSE、反向连接、定时器、监听器
```

配置文件 revision 与网关 runtime configVersion 各自计算，不混用。
IPC 成功后同步父子进程的发送、查询、验证等身份上下文；保留原有操作回执。

## 分阶段工作及依赖

1. **契约与差异计划**：固定脱敏影响计划与结果类型，识别账号、协议、动态及冷变更。
   以有效默认配置比较；不得在 Web 猜测重连范围。
2. **资源与生命周期**：协议构造、启动、停止都使用独立作用域；共享 HTTP Host
   归平台。账号连接变更先检查再释放，失败只恢复受影响的旧配置实例。
3. **运行态协调**：串行应用但不设置全局不可用；无变化不触发副作用。
   冷变更在热接口中拒绝。恢复失败明确标记需要恢复，不暗中重启。
4. **管理事务与 IPC**：先持久化意图和前后配置，再写入候选快照并派发同一操作。
   成功确认后提交结果；明确回滚才恢复旧文件。超时、断链、磁盘失败按未知处理，
   不重派、不伪造回滚成功，不允许后续写入绕过对账。
5. **交互**：校验后显示简洁影响摘要，详细列表渐进披露。热应用不弹全局重启提示；
   冷应用通过回执绑定的明确授权确认。保存成功保留准确执行结果。
6. **集成与验收**：下述用户可观察回归、构建、全量测试、打包边界与安装路径检查；
   记录跳过项和不能证明的真实平台能力。补用户文档及 patch Changeset。

运行态、管理事务、Web 可以在契约固定后并行；网关 IPC 和身份同步由主代理集成。
跨目录修改提前协调文件归属，所有代理不自行提交或推送，由主代理统一审查交付。

## 验收清单

- 账号 A 增删改时 B 的实例、连接和消息处理连续，网关 PID/instanceId 不变。
- 协议 P 更新时账号平台连接和协议 Q 不变，旧 P 路由消失，新 P 可用。
- general 默认值仅影响有效配置实际改变的协议。
- 共享 Webhook 首账号删改后其他账号仍可接入，重建不遗留永久 404。
- 明确启动失败只恢复受影响实例；恢复失败、进程退出、IPC 超时分别如实报告。
- 并发保存、与启停/版本切换竞争、CAS 失配、重复操作与迟到消息不重复派发。
- 成功后发送、查询、验证码入口使用新 configVersion；历史回执不丢失。
- 网关停止时只保存；进程级变更未授权不能重启。
- Web/CLI/TUI 对同一回执表达相同影响，取消重启不产生应用请求。
- HTTP、正反向 WS、SSE、定时器和事件监听随所属实例清理，无无关资源关闭。
