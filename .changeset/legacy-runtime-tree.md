增加旧服务运行目录的完整快照与校验基础能力，保留内部依赖链接并检测产物篡改。此能力尚未接入系统服务迁移入口。

迁移文件层区分原始备份、目标文件和回退文件，支持将服务定义及元数据恢复为独立旧工件路径，同时保留原始配置字节与历史备份。回退中断后只接受已知状态，第三方修改会阻止继续覆盖。

增加旧 Node 独立副本的保留与自检，并在 macOS 静态检查所有 Mach-O 切片的系统库依赖。Windows 原生依赖检查尚未实现。

将保留的运行目录及 Node 绑定到迁移备份与回退端口，校验原程序摘要、保留绝对配置路径，并扫描运行目录中的原生文件。补充 Linux ELF64 x64/arm64 glibc 与 Alpine/musl 系统库递归静态检查，拒绝非系统依赖路径。

自动捕获编排先持久化意图再保存工件，失败或结果未知时不派发停服操作。当前支持独立运行目录，混合目录及全局安装布局尚未接入默认迁移入口。

Linux 缓存检查仅验证实际依赖对应的候选库，不再因无关的第三方缓存条目拒绝 Node；实际外部依赖仍被拒绝。
