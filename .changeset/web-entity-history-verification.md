管理台改用 `/console` 下的 History 路由；账号与协议各自提供列表、详情和编辑子页，连接地址与管理操作按需进入详情，账号与协议详情相互可跳转。服务端为管理子页提供刷新直达回退，不占用网关协议路径。待办打开或刷新时自动只读查询当前设备的历史验证回执，已确认完成的旧操作不再要求手动查询才能处理新挑战；未知结果仍保持阻塞与原编号保护。

在线账号控制页核对发送操作的回执编号，错编号不能解除待确认状态；最近会话加载过旧页后仍会刷新新消息并保留分页位置，服务端已无旧页时清理本地过期条目。

账号列表、详情、成员和聊天历史保留管理服务返回的可操作错误提示；窄屏和平板将会话详情与成员列表放入按需打开的浮层，减少聊天区的常驻信息占用。

成员列表被响应预算截断时显示实际读取数量，不再误报固定 500 位；重试加载期间不展示旧截断提示。

会话详情浮层使用不透明主题底色，避免底层聊天文字透出干扰阅读。

手机从会话列表按 ID 打开会话时同步关闭列表浮层，避免新会话被旧列表遮挡；联系人与频道列表的截断提示也改为实际读取条目数量。

手机会话列表、分类与手动目标输入浮层统一使用不透明主题底色，避免多层内容重叠。

拆分聊天记录展示与窄屏会话列表交接模块，统一管理翻页滚动锚点和浮层焦点；聊天记录区可通过键盘聚焦并滚动，提供清晰的焦点边框。

发送回执确认仍在执行时恢复运行中状态并关闭放弃确认，查询期间不能放弃追踪；避免待执行消息被误当作未知并解除重复发送保护。

发送前复用管理服务的发送契约校验 UTF-8 字节与报文预算，长中文或转义报文超限时保留草稿就地提示，不创建无法查询的未知操作。

发送状态区分正在发送与正在查询回执，避免查询操作被表达为再次发送。

发送能力判断独立管理，统一好友、群、频道和直聊的场景能力与管理状态门禁；补充精确字节上限及修正草稿后重试的回归验证。

纯文本发送保留用户输入的首尾空格、缩进和换行；仅用去空白判断阻止空消息，不再改写实际正文。

账号发送与待办验证共用安全随机 UUID 生成方法，普通 HTTP 页面不再因 randomUUID 缺失卡住发送；安全随机数不可用时保留草稿并明确提示，不降级使用不安全随机数。

控制页消息输入框在输入法组词期间不再响应发送快捷键，也不拦截候选词确认；组词结束后 Ctrl/⌘+Enter 正常发送，普通 Enter 保留换行。
